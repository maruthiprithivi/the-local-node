# Leak check: prefix-reuse-3way kit

Scope: every file in this folder, every file and directory name, and the git history of the commit that adds it. Checked on 24 November 2026 (UTC+8) before handoff for publication. The search terms are described by category, not listed literally, so this file does not reintroduce them.

**Verdict: PASS.** No secrets, credentials, private host or network identifiers, personal data, internal agent or ticket IDs, or private absolute paths.

## Tools and patterns

- `gitleaks` 8.24.3 over the folder (`dir`) and over the branch history (`git`): no leaks found.
- A case-insensitive `rg` over contents and file names for: the test hosts' machine names, short host IDs and SSH aliases; the owner's usernames and home paths; internal workspace, bench-tree and results paths; tailnet and `.ts.net` names; private IPv4 ranges (10/8, 172.16/12, 192.168/16, 100.64/10); e-mail addresses; token prefixes (GitHub, `sk-`, `hf_`, `xox*`, `AKIA`) and private-key headers; vault references; `password`, `secret`, `api_key`, `token=`, `bearer`, `authorization`, `cookie`; internal ticket IDs, agent and bot names, and the name of an unrelated resident server on the test host.
- UTF-8 decode of every file, a symlink check, `bash -n` on the launch scripts and `reproduce.sh`, and a JSON parse of every `.json` and `.jsonl` line.

## Remaining matches (reviewed, benign)

- `127.0.0.1`: loopback binds inside the isolated containers.
- `/models`, `/out`, `/gguf`, `/cache`, `/root/.ollama`, `/usr/lib/ollama`: container-internal mount points and install paths.
- `bench.slice`, `bench-memguard`, `earlyoom` and the `bench-prefix-*` container names: the preconditions and names the original launch scripts check and use.
- Long hex strings: public image digests, the local SGLang image Id, model file and GGUF sha256 values, and stream/request IDs generated by the engines in `raw/`.
- `"host": 0` and similar keys in `raw/sglang-pairs.jsonl`: SGLang's own metric field names (host-memory cache tiers), not machine names.

## Changes from the original run files

- `raw/*-pairs.jsonl`, `summaries/*-summary.json`, `analyze_prefix.py`, `prefix_probe.py`, `launch/Modelfile`, `provenance/tensor_equiv.py`, `provenance/tensor-equiv.json`, `provenance/hf-weights.sha256`: byte-for-byte as produced by the run.
- `launch/*.sh`: header comments rewritten without internal host names, and one comment listing unrelated local ports replaced. Commands, flags and digests are unchanged.
- `provenance/gguf.sha256`: written from the run's GGUF checksum file and convert log (hash, size, tensor count, converter commit).
- `README.md`, `log-excerpts.md`, `reproduce.sh`, `table.py`, `LEAKCHECK.md`, `SHA256SUMS`: written for this kit.

## Files excluded and why

- Model weights, the 8.7 GB GGUF and the SGLang image tar: too large and not ours to redistribute; hashes only.
- Full server, import and watchdog logs: they carry host-specific paths and unrelated services. The lines the README relies on are in `log-excerpts.md`.
