## A minimal approach

Treat help/reset/exit as interface operations before appending user messages. Reset should mutate only the session's history list. Inject a recording provider and scripted input source into your wrapper; assert exact request roles/order and call counts. Catch EOF/KeyboardInterrupt around input acquisition, not every engine exception. Do not reset persisted task state just because the user started a fresh conversation.

## Test the explanation

Start from the lesson's successful fixture, then change exactly one input to reach its deliberate failure. The successful result should satisfy:

Messages remain in user/assistant order, help performs no model call, reset removes only session messages, and exit/interruption end input handling.

The failure must demonstrate:

Feed an input above the size limit, then EOF. No oversized message should enter history; EOF should exit cleanly rather than spin and repeatedly call the provider.

Use pytest's `tmp_path` for mutable files/databases and a recording fake for provider/handler calls. Inject time instead of waiting. Verify a negative assertion about the boundary, such as zero executions or unchanged bytes, as well as the visible error. Never substitute “the model said it was safe” for an assertion on host policy or actual state.

## Exercise extension reference

Keep this extension in your learning branch. The fragment demonstrates the minimal additional seam; integrate it only after the baseline test and deliberate-failure case are understood.

```python
def session_turn(provider, history, prompt, *, input_limit=4096):
    """Small session seam; tool execution still belongs to Engine."""
    if prompt == "/reset":
        return [], "session reset"
    if not isinstance(prompt, str) or len(prompt) > input_limit:
        raise ValueError("input exceeds limit")
    from course_harness.providers import assistant_message
    messages = [dict(message) for message in history]
    messages.append({"role": "user", "content": prompt})
    reply = provider.complete(messages)
    if reply.calls:
        raise ValueError("this conversation seam is text-only")
    messages.append(assistant_message(reply))
    return messages, reply.text

def test_reset_request_history():
    from course_harness.providers import FakeProvider, Reply
    provider = FakeProvider([Reply("first"), Reply("second")])
    history, _ = session_turn(provider, [], "one")
    history, _ = session_turn(provider, history, "/reset")
    history, _ = session_turn(provider, history, "two")
    assert [m["content"] for m in provider.requests[1]["messages"]] == ["two"]
```
