# Lesson 13 reference solution

Read [the lesson](../lessons/13-durable-state/README.md) first. This reference explains the smallest intended change in the shared package; it is not a second copy of the harness.

## A minimal approach

Persist the action identity and reviewed arguments, then record started before the synthetic mutation. Inject failure before completion persistence. On reopen, treat the action as uncertain and inspect the expected file/service/artifact postcondition. Do not rerun just because a completion row is absent. Resolution must be explicit and evidence-backed; if evidence is insufficient, retain uncertainty for human review. Validate persisted version and recovered approval/budget state before dispatch.

## Test the explanation

Start from the lesson's successful fixture, then change exactly one input to reach its deliberate failure. The successful result should satisfy:

Recorded completed actions replay results without repeat effects; started ambiguous actions require observation/resolution; approval scope and remaining budgets survive.

The failure must demonstrate:

Tamper a persisted version or reopen a started action without confirming its effect. The first must fail clearly; the second must remain inspectable and uncertain rather than silently repeat.

Use pytest's `tmp_path` for mutable files/databases and a recording fake for provider/handler calls. Inject time instead of waiting. Verify a negative assertion about the boundary, such as zero executions or unchanged bytes, as well as the visible error. Never substitute “the model said it was safe” for an assertion on host policy or actual state.

## A concrete test to adapt

This source example uses the delivered API. It is a starting point for a learner test, not a claim of execution. Save it in your own test file and extend its failure assertions on an approved development machine.

```python
from course_harness.persistence import DurableStore

def test_crash_is_uncertain(tmp_path):
    path = tmp_path / "state.sqlite"
    scope = {"operation": "fixture-write", "target": "event-plan"}
    store = DurableStore(path, clock=lambda: 100)
    store.create_run("run-1", {"actions": 2})
    store.request_action("run-1", "action-1", {"text": "reviewed"})
    store.approve_action("action-1", scope)
    store.consume("run-1", "actions")
    store.start_action("action-1", scope)
    # Simulate the effect occurring, then lose its completion record.
    observed_artifact = "reviewed"
    store.close()
    reopened = DurableStore(path, clock=lambda: 101)
    assert reopened.recover() == ["action-1"]
    assert reopened.action("action-1")["status"] == "uncertain"
    assert observed_artifact == "reviewed"
    reopened.reconcile("action-1", {"artifact": observed_artifact},
                       observed=True)
    assert reopened.action("action-1")["status"] == "completed"
    assert reopened.run("run-1")["budgets"]["actions"] == 1
    reopened.close()
```
