## A minimal approach

Build a new context list rather than shortening the stored history in place. Reserve space for constraints and metadata before adding bounded observations. Keep call/result groups together and append a clear truncation marker when excerpts are shortened. Assert both total bound and preserved unique constraint/trust markers. Do not promote a generated summary to trusted policy or claim exact token counts from character length.

## A concrete test to adapt

This source example uses the delivered API. It is a starting point for a learner test, not a claim of execution. Save it in your own test file and extend its failure assertions on an approved development machine.

```python
from copy import deepcopy
from course_harness.core import build_context

def test_context_marks_omission():
    history = [{"role": "system", "content": "host-policy-marker"},
               {"role": "user", "content": "x" * 9000},
               {"role": "user", "content": "current evidence"}]
    original = deepcopy(history)
    context = build_context(history, max_chars=512)
    assert history == original
    assert any("host-policy-marker" in m["content"] for m in context)
    assert any("TRUNCATED" in m["content"] for m in context)
```

## Exercise extension reference

Keep this extension in your learning branch. The fragment demonstrates the minimal additional seam; integrate it only after the baseline test and deliberate-failure case are understood.

```python
def bounded_excerpt(observation, *, limit=128):
    if limit < 1:
        raise ValueError("excerpt limit must be positive")
    text = observation["text"]
    excerpt = text[:limit]
    omitted = len(text) - len(excerpt)
    if omitted:
        excerpt += f" [TRUNCATED: {omitted} characters omitted]"
    return {"source": observation["source"], "trust": "untrusted",
            "text": excerpt, "omitted_chars": omitted}

def test_excerpt_preserves_source_and_omission():
    observation = {"source": "fixture-log", "text": "x" * 300}
    selected = bounded_excerpt(observation, limit=100)
    assert selected["source"] == "fixture-log"
    assert selected["omitted_chars"] == 200
    assert "TRUNCATED" in selected["text"]
    assert observation["text"] == "x" * 300

# The marker is extra metadata; reserve room for it in an aggregate bound.
# A summary/excerpt never replaces trusted host constraints.
```
