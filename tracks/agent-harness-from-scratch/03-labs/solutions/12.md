# Lesson 12 reference solution

Read [the lesson](../lessons/12-retries-and-cancellation/README.md) first. This reference explains the smallest intended change in the shared package; it is not a second copy of the harness.

## A minimal approach

Inject a sequence of errors/replies and record attempt count plus fake-time progression. Authentication must stop on the first call; retryable errors may continue only inside attempt/time limits. Cancellation during delay must be checked before another request begins. Keep action uncertainty separate from retryable provider transport. A mutation recorded as started but not completed belongs in reconciliation; replaying it automatically risks duplicate effects.

## Test the explanation

Start from the lesson's successful fixture, then change exactly one input to reach its deliberate failure. The successful result should satisfy:

Transient recovery uses bounded attempts; terminal errors stop; cancellation prevents new work; uncertain non-idempotent effects require reconciliation.

The failure must demonstrate:

A cancelled backoff should not trigger its next call. A terminal error should produce only one attempt. A continuously retryable error must reach the ceiling/deadline.

Use pytest's `tmp_path` for mutable files/databases and a recording fake for provider/handler calls. Inject time instead of waiting. Verify a negative assertion about the boundary, such as zero executions or unchanged bytes, as well as the visible error. Never substitute “the model said it was safe” for an assertion on host policy or actual state.

## A concrete test to adapt

This source example uses the delivered API. It is a starting point for a learner test, not a claim of execution. Save it in your own test file and extend its failure assertions on an approved development machine.

```python
from course_harness.core import retry_call

def test_retry_uses_fake_time():
    state = {"calls": 0, "now": 0.0}
    def operation():
        state["calls"] += 1
        if state["calls"] == 1:
            raise TimeoutError("synthetic transport timeout")
        return "recovered"
    def sleeper(delay):
        state["now"] += delay
    result = retry_call(operation,
                        retryable=lambda error: isinstance(error, TimeoutError),
                        clock=lambda: state["now"], sleep=sleeper,
                        deadline=1.0, attempts=2)
    assert result == "recovered"
    assert state["calls"] == 2
    assert 0 < state["now"] < 1
```

## Exercise extension reference

Keep this extension in your learning branch. The fragment demonstrates the minimal additional seam; integrate it only after the baseline test and deliberate-failure case are understood.

```python
def test_cancel_during_backoff():
    import pytest
    from course_harness.core import retry_call
    state = {"cancelled": False, "calls": 0}
    def operation():
        state["calls"] += 1
        raise TimeoutError("transient fixture")
    def sleeper(delay):
        state["cancelled"] = True
    with pytest.raises(InterruptedError, match="cancelled"):
        retry_call(operation, retryable=lambda error: True,
                   sleep=sleeper, cancelled=lambda: state["cancelled"])
    assert state["calls"] == 1

def test_terminal_error_is_not_retried():
    import pytest
    from course_harness.core import retry_call
    calls = []
    def operation():
        calls.append(1)
        raise PermissionError("terminal fixture")
    with pytest.raises(PermissionError):
        retry_call(operation, retryable=lambda error: False)
    assert calls == [1]
```
