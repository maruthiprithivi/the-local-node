# Lesson 6 reference solution

Read [the lesson](../lessons/06-permissions-and-approvals/README.md) first. This reference explains the smallest intended change in the shared package; it is not a second copy of the harness.

## A minimal approach

Snapshot the policy before feeding injected data and assert it remains unchanged. Obtain a digest for the exact approved proposal, then change a relevant argument or target and assert the handler is not called. Approval does not override host deny rules. Keep approved/executed state distinct: an approval is permission, not evidence an effect happened. In cancellation tests, set the stop condition before dispatch and inspect both the trace and fixture state.

## Test the explanation

Start from the lesson's successful fixture, then change exactly one input to reach its deliberate failure. The successful result should satisfy:

Read operations continue, denial has zero effects, and only an approval matching the exact request can pass the effect gate.

The failure must demonstrate:

Present a valid but forbidden request. It should yield tool_denied/run_stopped(denied), with no handler call. Present an unapproved write in semi mode; expect approval_required rather than success.

Use pytest's `tmp_path` for mutable files/databases and a recording fake for provider/handler calls. Inject time instead of waiting. Verify a negative assertion about the boundary, such as zero executions or unchanged bytes, as well as the visible error. Never substitute “the model said it was safe” for an assertion on host policy or actual state.

## A concrete test to adapt

This source example uses the delivered API. It is a starting point for a learner test, not a claim of execution. Save it in your own test file and extend its failure assertions on an approved development machine.

```python
from course_harness.tools import FixtureWorld, scenario_tools, Policy

def test_approval_is_exact():
    world = FixtureWorld()
    registry = scenario_tools(world)
    tool = registry.tools["record_artifact"]
    policy = Policy("semi", frozenset({"record_artifact"}), clock=lambda: 100)
    args = {"name": "event-plan", "text": "reviewed"}
    assert policy.decide(tool, args) == "ask"
    policy.approve(tool, args)
    assert policy.decide(tool, args) == "allow"
    assert policy.decide(tool, {**args, "text": "changed"}) == "ask"
    assert not world.artifacts  # Permission alone performs no effect.
```
