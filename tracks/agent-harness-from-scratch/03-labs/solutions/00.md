## A minimal approach

Keep parsing and mutation separate. Catch only `json.JSONDecodeError` to add a readable message, chaining the original exception. Validate every title and return a new list of dictionaries. The failure test must compare original file bytes after the exception. Do not catch every exception and return `[]`: that makes a damaged file indistinguishable from an intentionally empty task list.

## A concrete test to adapt

This source example uses the delivered API. It is a starting point for a learner test, not a claim of execution. Save it in your own test file and extend its failure assertions on an approved development machine.

```python
from pathlib import Path
import json

def load_tasks(path):
    try:
        value = json.loads(Path(path).read_text(encoding="utf-8"))
    except json.JSONDecodeError as error:
        raise ValueError("task file contains invalid JSON") from error
    if not isinstance(value, list):
        raise ValueError("task file must contain a list")
    for item in value:
        if not isinstance(item, dict) or not isinstance(item.get("title"), str):
            raise ValueError("every task needs a string title")
    return [dict(item) for item in value]

def test_invalid_json_preserves_file(tmp_path):
    import pytest
    path = tmp_path / "tasks.json"
    path.write_text("{broken", encoding="utf-8")
    original = path.read_bytes()
    with pytest.raises(ValueError, match="invalid JSON"):
        load_tasks(path)
    assert path.read_bytes() == original
```
