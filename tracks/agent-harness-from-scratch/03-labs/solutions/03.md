# Lesson 3 reference solution

## A minimal approach

Use injected transport responses and local fixture bytes, not patched credentials that accidentally reach a real endpoint. Check the request's selected model, endpoint, timeout, and output bound. Missing required credentials must short-circuit transport. Assert authentication errors are classified terminal and diagnostics exclude the synthetic key. Keep provider-specific field and finish-rule checks alongside the shared contract tests; do not infer all five APIs from one OpenAI-shaped fixture.

## Test the explanation

Start from the lesson's successful fixture, then change exactly one input to reach its deliberate failure. The successful result should satisfy:

Fake remains the default; mock transport captures a bounded request; missing credentials and unsupported required capabilities fail explicitly.

The failure must demonstrate:

Omit a required key for a hosted adapter. Failure must occur before the recording transport is called. Then request a capability the adapter does not declare.

Use pytest's `tmp_path` for mutable files/databases and a recording fake for provider/handler calls. Inject time instead of waiting. Verify a negative assertion about the boundary, such as zero executions or unchanged bytes, as well as the visible error. Never substitute “the model said it was safe” for an assertion on host policy or actual state.

## A concrete test to adapt

This source example uses the delivered API. It is a starting point for a learner test, not a claim of execution. Save it in your own test file and extend its failure assertions on an approved development machine.

```python
from course_harness.providers import OpenAIProvider, FixtureTransport

def test_mocked_provider_boundary():
    transport = FixtureTransport([{
        "choices": [{"message": {"content": "fixture reply"},
                     "finish_reason": "stop"}],
        "usage": {"prompt_tokens": 4, "completion_tokens": 2},
    }])
    provider = OpenAIProvider("fixture-model", transport=transport,
                              timeout=2, max_output_tokens=32)
    reply = provider.complete([{"role": "user", "content": "fixture"}])
    assert reply.text == "fixture reply"
    assert reply.usage["input_tokens"] == 4
    assert transport.requests[0]["timeout"] == 2
```
