## A minimal approach

Put scripted read calls and final reply in order and retain stable call identifiers. Assert matching request/result identifiers and exact handler count. For the looping provider, reduce limits rather than waiting in real time; expect a controller-owned bounded stop. A duplicate identifier must not become two ambiguous effects. Budget checks must occur before the next model/tool invocation, not after a side effect has already exceeded the configured ceiling.

## Test the explanation

Each result matches its request identifier; the successful script stops as final; the looping script stops as step_limit or call_limit.

The failure must demonstrate:

Return duplicate call identifiers or request more calls than the call limit. Check rejection/stop before the extra handler executes. An unmatched result must not be presented as evidence for another request.

Use pytest's `tmp_path` for mutable files/databases and a recording fake for provider/handler calls. Inject time instead of waiting. Verify a negative assertion about the boundary, such as zero executions or unchanged bytes, as well as the visible error. Never substitute “the model said it was safe” for an assertion on host policy or actual state.

## A concrete test to adapt

This source example uses the delivered API. It is a starting point for a learner test, not a claim of execution. Save it in your own test file and extend its failure assertions on an approved development machine.

```python
from course_harness.core import Engine, Limits
from course_harness.providers import FakeProvider, Reply, ToolCall
from course_harness.tools import FixtureWorld, scenario_tools, Policy

def test_loop_terminates():
    world = FixtureWorld()
    registry = scenario_tools(world)
    replies = [Reply(calls=(ToolCall(str(i), "observe_health", {}),))
               for i in range(3)]
    policy = Policy(allowed=frozenset({"observe_health"}))
    result = Engine(FakeProvider(replies), registry, policy,
                    limits=Limits(steps=2)).run("inspect")
    assert result.stop_reason == "step_limit"
    assert world.restarts == 0
```
